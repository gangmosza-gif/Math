# ฟอนต์ในโปรแกรม

ฟอนต์ทั้งหมดในโฟลเดอร์นี้ดาวน์โหลดจาก Google Fonts ด้วย `tools/fetch_fonts.py` เพื่อให้โปรแกรมใช้งานได้โดยไม่ต้องต่ออินเทอร์เน็ต
ทุกฟอนต์ใช้สัญญาอนุญาต **SIL Open Font License 1.1** (Roboto ใช้ Apache License 2.0) ซึ่งอนุญาตให้นำไปรวมกับโปรแกรมและแจกจ่ายได้
รายชื่อฟอนต์และจำนวนไฟล์ดูได้ใน `index.json`
