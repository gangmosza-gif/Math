## 3. สิ่งที่ตกลงกับเจ้าของโปรเจกต์

- ใช้งานออฟไลน์ 100% ไม่ดึง API/รูป/ฟอนต์จากภายนอกตอนใช้งาน ใช้พื้นที่มากขึ้นได้
- คลังรูป: เลือกแผน "ฟอนต์ + ตัด picsum + รูป CC0" (ดึงจาก Wikimedia Commons ทีละรูป); **ไม่ใส่อีเมลติดต่อใน User-Agent** (เจ้าของสั่งหยุดไว้ก่อน)
- เรื่อง "เปิด HTML ในโฟลเดอร์แล้วอ่าน/บันทึกไฟล์ในโฟลเดอร์นั้น" → เจ้าของให้พักไว้ทำทีหลัง (ตอนนี้งานบันทึกในเบราว์เซอร์ + ไฟล์โปรเจกต์ .json)
- งานภาพองค์ประกอบด้วย AI → พักไว้ก่อน (ดูข้อ 5)
- เทมเพลต: ออกแบบเองให้ดูมืออาชีพแบบ Canva ไม่ให้ดูเหมือน AI ทำ, ใช้เครื่องมือของโปรแกรมเองสร้าง

## 6. เริ่มทำงานต่อบนเครื่องตัวเอง

```bash
git clone https://github.com/gangmosza-gif/Math.git
cd Math && git checkout claude/upbeat-cerf-2evbgk
cd design-studio && npm install
npx playwright install chromium      # สำหรับชุดทดสอบ (ครั้งแรก)
npm run dev                          # เปิด http://localhost:5173
```
แล้วเปิด Claude Code ในโฟลเดอร์ `Math` — มันจะอ่าน `CLAUDE.md` เอง บอกว่า "อ่าน docs/PROJECT-STATUS.md แล้วทำงานต่อ" ได้เลย
