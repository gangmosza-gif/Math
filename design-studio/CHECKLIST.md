# เช็กลิสต์ฟีเจอร์เทียบกับ Canva

เอกสารนี้ไล่ดูทุกส่วนของ Canva (ตัวแก้ไข, ข้อความ, รูปภาพ, กราฟิก/อินโฟกราฟิก, เอกสาร, งานนำเสนอ, รายงาน, การส่งออก และหน้าแรก) แล้วตรวจกับ Lai Studio ทีละข้อ

ทุกข้อที่ระบุว่า "ผ่าน" มีชุดทดสอบอัตโนมัติ (`tests/e2e.cjs`) ที่เปิดแอปในเบราว์เซอร์จริง กดใช้งาน และตรวจผล ใช้คำสั่ง `npm test` เพื่อรันซ้ำ

**สัญลักษณ์**

| สัญลักษณ์ | ความหมาย |
|---|---|
| ✅ | มีอยู่แล้วและผ่านการทดสอบ |
| 🆕 | เพิ่มในรอบนี้และผ่านการทดสอบ |
| 🔧 | เจอปัญหาระหว่างตรวจ แก้แล้ว และผ่านการทดสอบซ้ำ |
| ⚠️ | มีบางส่วน (รายละเอียดอยู่ในหมายเหตุ) |
| ❌ | ยังไม่มี แต่ทำได้ในรอบถัดไป |
| ⛔ | ไม่ทำในโปรเจกต์นี้ เพราะเป็นวิดีโอ/AI/ทำงานร่วมกันหลายคน (ตกลงกันไว้แล้ว) หรือต้องมีเซิร์ฟเวอร์และบัญชีผู้ใช้ |

**ผลการทดสอบล่าสุด:**
- ชุดทดสอบหลัก (`tests/e2e.cjs`) ผ่าน **120 / 120 รายการ**
- ชุดทดสอบไฟล์ PowerPoint/Word (`tests/office.cjs`) ผ่าน **50 / 50 รายการ**
- ไม่พบ JavaScript error ตลอดการทดสอบ

### วิธีทดสอบ (`npm run test:office`)

ใช้งานตัวอย่าง 3 ชุด รวม 8 หน้า:
- หน้ารวมทุกองค์ประกอบ
- เอกสาร A4: ใบงาน ประกาศ เกียรติบัตร
- สไลด์ 16:9: หน้าแรก งานสัมมนา โปรโมชัน เมนู

ส่งออกแต่ละชุดเป็น PowerPoint และ Word แล้วเปิดด้วย LibreOffice เพื่อตรวจ 7 เรื่อง:
1. ไฟล์ถูกต้องและจำนวนหน้าตรงกับงาน
2. ข้อความทุกจุดอยู่ในไฟล์เป็นข้อความจริงที่แก้ไขได้
3. ข้อความที่แสดงผลจริงครบ ไม่มีอักขระเสียหรือภาษาแปลก ๆ
4. ไฟล์อ้างถึงฟอนต์ตามงานออกแบบ
5. ตอนแสดงผลใช้ฟอนต์นั้นจริง ไม่ถูกแทนที่
6. ตาราง/กราฟเป็นวัตถุจริง จำนวนครบ
7. เทียบภาพทีละหน้ากับต้นฉบับ (เกณฑ์: ค่าต่างเฉลี่ย < 8 จาก 255 และพิกเซลที่ต่างชัด < 6%)

ผลล่าสุด: ทุกหน้ามีค่าต่างเฉลี่ย **1.7–6.5** (ยกเว้นพื้นที่กราฟ ซึ่งวัดแยกและผ่านเกณฑ์ของกราฟ)

**ข้อจำกัดที่ควรรู้**
- **ต้องมีฟอนต์ในเครื่อง:** เครื่องที่เปิดไฟล์ต้องติดตั้งฟอนต์ที่ใช้ในงาน (Google Fonts ฟรีทั้งหมด) ไม่เช่นนั้นโปรแกรมจะใช้ฟอนต์อื่นแทน ข้อความยังครบแต่หน้าตาจะเปลี่ยน
- **หน้าตากราฟ:** กราฟถูกส่งออกเป็นกราฟจริงที่แก้ข้อมูลได้ PowerPoint/Word จึงวาดเส้นแกนและขนาดป้ายตัวเลขตามแบบของตัวเอง
- **ทดสอบด้วย LibreOffice เท่านั้น:** ยังไม่ได้เปิดทดสอบใน Microsoft Office จริง
- **การซ้อนตารางใน Word บน LibreOffice:** LibreOffice วาดตารางลอยใน Word ไว้บนภาพที่วางทับเสมอ ถ้าในงานมีภาพทับตาราง ลำดับการซ้อนอาจกลับกันเมื่อเปิดด้วย LibreOffice

ทุกข้อแก้แล้ว และรันชุดทดสอบทั้งหมดซ้ำหลังแก้แต่ละข้อ เพื่อยืนยันว่าส่วนอื่นยังทำงานปกติ

| # | ปัญหา | ผลกระทบต่อผู้ใช้ | วิธีแก้ |

| 2 | ลิงก์ภาษาไทยใน PDF ไม่เป็นรูปแบบมาตรฐาน | บางโปรแกรมเปิดลิงก์ใน PDF ไม่ได้ | แปลงเป็น percent-encoding ก่อนบันทึก |

| 10 | Word: ข้อความทุกจุดกลายเป็นภาพ | แก้ข้อความใน Word ไม่ได้ | ไม่นับค่าเส้นขอบเริ่มต้นของ Fabric (1px แต่ไม่มีสี) เป็นเส้นขอบจริง |
| 11 | สีเฉพาะคำคลาดตำแหน่งใน PowerPoint/Word | คำผิดถูกทำสี | นับตำแหน่งตามกลุ่มอักขระ (grapheme) แบบเดียวกับตัวแก้ไข เช่น "ตั้" นับเป็น 1 ตำแหน่ง |

| 13 | ข้อความใน PowerPoint/Word ต่ำกว่าต้นฉบับ | ตำแหน่งเพี้ยน | วัดระยะเลื่อนจริงกับฟอนต์ 10 แบบ แล้วชดเชยตามสูตร (เหลือคลาด ≤ 1px) |
