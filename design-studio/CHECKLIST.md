# เช็กลิสต์ฟีเจอร์เทียบกับ Canva

เอกสารนี้ไล่ดูทุกส่วนของ Canva (ตัวแก้ไข, ข้อความ, รูปภาพ, กราฟิก/อินโฟกราฟิก, เอกสาร, งานนำเสนอ, รายงาน, การส่งออก และหน้าแรก) แล้วตรวจกับ Lai Studio ทีละข้อ

ทุกข้อที่ระบุว่า "ผ่าน" มีชุดทดสอบอัตโนมัติ (`tests/e2e.cjs`) ที่เปิดแอปในเบราว์เซอร์จริง กดใช้งาน และตรวจผล ใช้คำสั่ง `npm test` เพื่อรันซ้ำ

**สัญลักษณ์**

| สัญลักษณ์ | ความหมาย |
|---|---|
| ✅ | มีอยู่แล้วและผ่านการทดสอบ |
| 🆕 | เพิ่มในรอบนี้และผ่านการทดสอบ |
| 🔧 | เจอปัญหาระหว่างตรวจ แก้แล้ว และผ่านการทดสอบซ้ำ |
| ⚠️ | มีบางส่วน (รายละเอียดอยู่ในหมายเหตุ) |
| ❌ | ยังไม่มี แต่ทำได้ในรอบถัดไป |
| ⛔ | ไม่ทำในโปรเจกต์นี้ เพราะเป็นวิดีโอ/AI/ทำงานร่วมกันหลายคน (ตกลงกันไว้แล้ว) หรือต้องมีเซิร์ฟเวอร์และบัญชีผู้ใช้ |

**ผลการทดสอบล่าสุด: ผ่าน 111 / 111 รายการ** และไม่พบ JavaScript error ตลอดการทดสอบ

## สรุปปัญหาที่พบระหว่างตรวจและแก้แล้ว

ทุกข้อแก้แล้ว และรันชุดทดสอบทั้งหมดซ้ำหลังแก้แต่ละข้อ เพื่อยืนยันว่าส่วนอื่นยังทำงานปกติ

| # | ปัญหา | ผลกระทบต่อผู้ใช้ | วิธีแก้ |
|---|---|---|---|
| 1 | การเปลี่ยนหน้าถูกนับเป็นขั้นเลิกทำ | กดเลิกทำแล้วแค่สลับหน้า งานไม่ย้อนกลับ | ไม่นับการเปลี่ยนหน้า และพาไปหน้าที่ถูกแก้ไขแทน |
| 2 | ลิงก์ภาษาไทยใน PDF ไม่เป็นรูปแบบมาตรฐาน | บางโปรแกรมเปิดลิงก์ใน PDF ไม่ได้ | แปลงเป็น percent-encoding ก่อนบันทึก |
| 3 | การจัดตารางใหม่หลัง "แทนที่ทั้งหมด" เพิ่มขั้นเลิกทำเกินมา | ต้องกดเลิกทำ 2 ครั้ง | ปรับประวัติการเลิกทำในที่เดิม ไม่เพิ่มขั้นใหม่ |
| 4 | การใส่เลขหน้ากินขั้นเลิกทำ 2 ขั้น | ต้องกดเลิกทำ 2 ครั้ง | จัดตำแหน่งก่อนเพิ่มลงงาน ให้เป็นขั้นเดียว |
| 5 | ระบบถือว่าฟอนต์พร้อมก่อนไฟล์ฟอนต์จะมาถึง | ข้อความ/ตารางถูกจัดด้วยฟอนต์สำรองแล้วไม่แก้กลับ | รอให้ไฟล์ฟอนต์ (stylesheet) โหลดก่อน และจัดตาราง/กราฟใหม่เมื่อฟอนต์มาถึง |
| 6 | เมนูป๊อปอัปบางครั้งปิดเองทันที (รอบก่อน) | กดเลือกสีหรือเมนูแล้วไม่มีผล | ล้างตัวดักคลิกที่ค้างอยู่ |
| 7 | กด Esc ปิดเมนูแล้วยกเลิกการเลือกไปด้วย (รอบก่อน) | วัตถุหลุดจากการเลือก | ให้ Esc ปิดแค่เมนู |
| 8 | แทนที่รูปที่มีเส้นขอบแล้วรูปใหญ่ขึ้น (รอบก่อน) | ขนาดรูปเพี้ยน | คิดขนาดโดยไม่รวมเส้นขอบ |
