สคริปต์: `tests/journey.cjs` — ใช้โปรแกรมด้วยเมาส์ คีย์บอร์ด แผง และเมนูจริง ทำต่อเนื่องบนงานเดียวกันตั้งแต่หน้าแรกจนส่งออกไฟล์
รัน: `npm run build && node tests/journey.cjs` (หรือ `STAGE=n` เพื่อหยุดที่ขั้น n) · รายงาน: `tests/report-journey/REPORT.md`

## ปัญหาที่พบจากการใช้งานจริง และการแก้

1. ✅ **ลากคลุมเลือกหลายชิ้นเริ่มจากพื้นที่สีเทารอบหน้าไม่ได้** (ต้องเริ่มในหน้ากระดาษเท่านั้น ซึ่งยากเมื่อมีของเต็มหน้า) → เพิ่มกรอบเลือกที่เริ่มจากพื้นที่สีเทาได้ (Shift = เพิ่มจากที่เลือกไว้)
2. ✅ **ดับเบิลคลิกข้อความที่อยู่ในกลุ่มแล้วแก้ไม่ได้** ต้องยกเลิกกลุ่มก่อน → พิมพ์แก้ในกลุ่มได้ทันทีเหมือน Canva แล้วกลับเข้ากลุ่มที่เดิม ลำดับชั้นเดิม
3. ✅ **จับมุม/ขอบของวัตถุที่ยื่นออกนอกหน้าไม่ได้** (พื้นที่วาดเท่ากับขอบหน้าพอดี มุมที่อยู่นอกหน้าจึงถูกตัด) → พื้นที่วาดมีขอบรอบหน้า จุดจับแสดงและลากได้นอกหน้า ส่วนเนื้อหายังแสดงเฉพาะในหน้า
4. ✅ **ไอคอนสีเดียวที่เป็นชิ้นเดียว (เช่น หัวใจ) แสดงแถบเครื่องมือของรูปทรง** มีปุ่ม "สีพื้น" ที่กดแล้วไม่เปลี่ยนอะไร (ไอคอนเป็นเส้น) → กราฟิกสีเดียวทุกแบบมีปุ่ม "สีกราฟิก" ปุ่มเดียวที่เปลี่ยนทั้งชิ้น
5. ✅ **กดกลางเส้นตรงเพื่อย้าย กลายเป็นยืดเส้นเป็นแถบหนา** (จุดจับบน/ล่างของเส้นตรงทับอยู่บนเส้นพอดี) → เส้นตรงมีจุดจับแค่ปลายสองข้าง + หมุน เหมือน Canva กดกลางเส้นแล้วย้ายได้
6. ✅ **ค้นหา "หัวใจ" ไม่เจอไอคอนหัวใจธรรมดา** (คลังตัดไอคอนตามตัวอักษรที่ 140 แบบ ไอคอนพื้นฐานอย่าง heart หลุด) → เลือกไอคอนพื้นฐานก่อนแบบแยกย่อย และเรียงผลค้นหาให้ชื่อที่ตรงที่สุดขึ้นก่อน
7. ℹ️ ป๊อปอัปเอฟเฟกต์ปิดทันทีหลังเลือก 1 แบบ (Canva ค้างไว้ให้ลองแบบอื่นต่อ) — ใช้งานได้ ยังไม่แก้
8. ℹ️ กล่องข้อความใหม่วางกลางหน้าทับของเดิม (Canva ทำแบบเดียวกัน) — ไม่ถือเป็นบั๊ก
