## 1. หน้าแรก: เปิดโปรแกรม ค้นหาเทมเพลต เลือกขนาดงาน

| ผล | ขั้นตอน | หมายเหตุ |
|---|---|---|
| ✅ | เปิดโปรแกรมได้ ไม่มีข้อผิดพลาด แสดงขนาดงาน เทมเพลตแนะนำ และช่องค้นหา | 14 ขนาด |
| ✅ | ค้นหาเทมเพลต "ข้อเสนอโครงการ" จากหน้าแรก แล้วเห็นผล | 33 ผล |
| ✅ | เลือกขนาด "งานนำเสนอ 16:9" → เข้าหน้าแก้ไข หน้ากระดาษพอดีจอ | 1920×1080 ซูม 51% |

## 2. พิมพ์ข้อความไทยด้วยคีย์บอร์ด: คำไม่ตก ไม่ขาด ตัดบรรทัดตรงคำ

| ผล | ขั้นตอน | หมายเหตุ |
|---|---|---|
| ✅ | เพิ่มหัวเรื่องจากแผงข้อความ แล้วดับเบิลคลิกเข้าโหมดพิมพ์ |  |
| ✅ | ลบข้อความเดิม (Ctrl+A, Backspace) แล้วพิมพ์หัวเรื่องไทยทีละตัว: ได้ครบทุกตัวอักษร สระ วรรณยุกต์ | สวัสดีครับ ยินดีต้อนรับสู่ห้องเรียน |
| ✅ | พิมพ์เร็ว (ไม่หน่วง) ต่อท้าย + ขึ้นบรรทัดใหม่ด้วย Enter: ไม่มีตัวอักษรหาย |  |
| ✅ | แก้คำผิดกลางประโยค: ลูกศรซ้าย + Backspace + พิมพ์แทน ได้ตำแหน่งถูกต้อง |  |
| ✅ | เพิ่มเนื้อความ แล้ววางย่อหน้ายาว (Ctrl+V จากคลิปบอร์ด): ข้อความครบ |  |
| ✅ | ย่อกล่องเนื้อความให้แคบ (ลากที่จับด้านขวา): ตัดบรรทัดตรงรอยต่อคำทุกบรรทัด ไม่ตัดกลางคำ | 4 บรรทัด กว้าง 446 |
| ✅ | ข้อความไม่ล้นกรอบ: ความสูงกล่องพอดีกับทุกบรรทัด และอยู่ในหน้า |  |
| ✅ | เลิกทำ (Ctrl+Z) แล้วทำซ้ำ (Ctrl+Y): ข้อความกลับมาถูกต้อง |  |
| ✅ | เปลี่ยนฟอนต์เป็น Sarabun / Kanit / Itim: ข้อความเดิมครบ และยังตัดบรรทัดตรงคำ | Sarabun 4 บรรทัด, Kanit 4 บรรทัด, Itim 4 บรรทัด |
| ✅ | ภาพหน้าจอหลังพิมพ์ |  |

## 3. จัดรูปแบบข้อความด้วยแถบเครื่องมือ (คลิกปุ่มจริง)

| ผล | ขั้นตอน | หมายเหตุ |
|---|---|---|
| ✅ | คลิกเลือกหัวเรื่องบนหน้า → แถบเครื่องมือข้อความขึ้น |  |
| ✅ | เปลี่ยนฟอนต์จากรายการ: ค้นหา "Prompt" แล้วคลิก |  |
| ✅ | ขนาดตัวอักษร: กด + สองครั้ง และพิมพ์ 72 ในช่อง | 97.2 → 105 → 72 |
| ✅ | ตัวหนา / ตัวเอียง / ขีดเส้นใต้ เปิดแล้วปิดได้ | หนา/เอียง/เส้นใต้ true,false,false → false,true,true → true,false,false |
| ✅ | สีตัวอักษร: เปิดจานสี พิมพ์รหัส #1E5EFF |  |
| ✅ | จัดตำแหน่งข้อความ: คลิกวน ซ้าย → กลาง → ขวา | right → justify → left |
| ✅ | ระยะห่างตัวอักษรและบรรทัด (สไลเดอร์ในป๊อปอัป) | [144,2.05] |
| ✅ | เอฟเฟกต์ข้อความ: เงา แล้วเปลี่ยนเป็นขอบ (outline) และกลับเป็นไม่มี |  |
| ✅ | ข้อความยังครบหลังจัดรูปแบบทั้งหมด |  |

## 4. รูปภาพ: อัปโหลด ย้าย ย่อ ครอบตัด (ลากขอบจริง) แทนที่รูป

| ผล | ขั้นตอน | หมายเหตุ |
|---|---|---|
| ✅ | อัปโหลดรูปจากเครื่อง (แผงอัปโหลด): รูปลงหน้าให้ทันที และมีในรายการอัปโหลด | 972×648 |
| ✅ | ย่อรูปจากมุมขวาล่าง แล้วลากไปมุมขวาบน (ลากจริงด้วยเมาส์) | 461×308 ที่ 1550,331 |
| ✅ | ครอบตัด: ดับเบิลคลิกรูป → ลากขอบบนลง และขอบขวาเข้า → เสร็จสิ้น | 461×308 → 381×189 |
| ✅ | ครอบตัดแบบสัดส่วน 1:1 จากแถบเครื่องมือ แล้วยกเลิก (Esc) — รูปไม่เปลี่ยน |  |
| ✅ | ครอบตัด 16:9 แล้วกด Enter ยืนยัน: รูปเป็น 16:9 |  |
| ✅ | รูปทรงกรอบ: เปลี่ยนรูปเป็นวงกลม (ปุ่ม "กรอบ") |  |
| ✅ | ปรับแต่งรูป: ความสว่าง/ความอิ่มตัว (สไลเดอร์) แล้วรูปยังอยู่ที่เดิม |  |
| ✅ | ภาพหน้าจอหลังจัดการรูป |  |

## 5. เลือกหลายชิ้น (Shift+คลิก, ลากคลุม) จัดกลุ่ม ย้ายทั้งกลุ่ม ยกเลิกกลุ่ม

| ผล | ขั้นตอน | หมายเหตุ |
|---|---|---|
| ✅ | Shift+คลิก: หัวเรื่อง + เนื้อความ + รูป → เลือกได้ 3 ชิ้น แถบเครื่องมือหลายชิ้นขึ้น |  |
| ✅ | จัดกลุ่มด้วยปุ่ม "จัดกลุ่ม" → เป็น 1 กลุ่ม ข้อความในกลุ่มครบ |  |
| ✅ | ลากกลุ่มไปทางซ้าย 200 px: ทุกชิ้นขยับเท่ากัน | ขยับ 198 px |
| ✅ | ดับเบิลคลิกข้อความในกลุ่ม → พิมพ์แก้ได้ทันที (ไม่ต้องยกเลิกกลุ่ม) แล้วกลุ่ม ตำแหน่ง และลำดับชั้นเหมือนเดิม | ะคุณธรรม ครบ |
| ✅ | ยกเลิกกลุ่ม (Ctrl+Shift+G): ได้ 3 ชิ้นแยกกัน ตำแหน่งเดิม ข้อความเดิม |  |
| ✅ | ลากคลุม (marquee) จากพื้นที่ว่าง: เลือกได้ทุกชิ้นที่อยู่ในกรอบ แล้ว Ctrl+G |  |
| ✅ | ทำสำเนากลุ่ม (Ctrl+D) แล้วเลิกทำ 2 ครั้ง: กลับเป็น 3 ชิ้นแยก |  |
| ✅ | ภาพหน้าจอหลังจัดกลุ่ม |  |
