# เช็คลิสต์ทดสอบเต็มระบบ Lai Studio (ทีละส่วน)

วิธีทดสอบแต่ละส่วน:
1. รันเทสต์อัตโนมัติเฉพาะส่วน: `ONLY=<เลขส่วน> node tests/e2e.cjs` (ส่วน O/D/I ใช้ชุดเทสต์ของตัวเอง)
2. ตรวจเพิ่มด้วยเบราว์เซอร์จริง (เดสก์ท็อป + จอมือถือ) ในจุดที่เทสต์ยังไม่ครอบคลุม
3. พบปัญหา → แก้ → ทดสอบซ้ำจนผ่าน → บันทึกในตารางด้านล่าง
