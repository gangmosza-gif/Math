# Lai Studio — โปรแกรมออกแบบกราฟิกบนเว็บ

เว็บแอปออกแบบกราฟิกภาษาไทย ทำงานในเบราว์เซอร์ทั้งหมด (ไม่ต้องมีเซิร์ฟเวอร์) งานทุกชิ้นบันทึกอัตโนมัติไว้ในเบราว์เซอร์ (IndexedDB)

## ความสามารถ

- **ขนาดสำเร็จรูป** – โพสต์ IG, สตอรี่/TikTok, Facebook, YouTube Thumbnail, สไลด์ 16:9, A4, A3, ใบงาน, เกียรติบัตร, นามบัตร, โลโก้ หรือกำหนดเอง และ **ปรับขนาดงาน** ภายหลังได้ (ย่อ/ขยายเนื้อหาตาม)
- **เทมเพลต** 92 แบบ ใน 13 หมวด (รวมอินโฟกราฟิก 20 แบบ) ค้นหาและกรองตามหมวดได้ ปรับตามขนาดงานอัตโนมัติ
- **ข้อความ** – ข้อความโค้ง, รายการแบบจุด/ตัวเลข, ฟอนต์ไทย 21 แบบ + อังกฤษ 12 แบบ (Google Fonts), ขนาด, สี, หนา/เอียง/ขีดเส้นใต้/ขีดฆ่า, จัดแนว, ตัวพิมพ์ใหญ่-เล็ก, ระยะห่างตัวอักษร/บรรทัด, เอฟเฟกต์ (เงา, ขอบ, กลวง, นีออน, ไฮไลต์), ชุดข้อความสำเร็จรูป, จัดสไตล์เฉพาะตัวอักษรที่เลือกขณะพิมพ์
- **องค์ประกอบ** – รูปทรง 24 แบบ + รูปทรงอีก 9 ตระกูล 68 แบบ (ก้อนเมฆ หัวใจ แบนเนอร์ หยดน้ำ ฟันเฟือง ดาวแฉก ดอกไม้ รูปทรงอิสระ กล่องคำพูด), เส้น 7 แบบ, สติกเกอร์อีโมจิ และ **คลังกราฟิก 1,559 ชิ้น 18 คอลเลกชัน** (ดอกไม้ สัตว์ อาหาร การเรียน เทศกาล เดินทาง ราศี อากาศ กีฬา อีโมจิ สติกเกอร์ 3 มิติ ภาพวาดลายมือ ภาพประกอบธุรกิจ/การศึกษา ไอคอนเส้นที่เปลี่ยนสีได้ และโลโก้โซเชียล) ค้นหาเป็นภาษาไทยได้ มีแถวใช้งานล่าสุด
- **รูปภาพ** – อัปโหลด / ลากวาง / วางจากคลิปบอร์ด, คลังรูปฟรี 993 รูป (Lorem Picsum) และลวดลายเวกเตอร์ 72 แบบ, ฟิลเตอร์และปรับแสง-สี-เบลอ, ครอบตัดโดยลากขอบบนรูป, กรอบรูปทรง (วงกลม, มุมมน, ดาว, หัวใจ, หกเหลี่ยม), เส้นขอบ, ตั้งเป็นพื้นหลัง
- **พื้นหลัง** – สีพื้น, ไล่เฉดสี, ภาพพื้นหลัง
- **ตาราง** – แก้ข้อมูลในช่อง เพิ่ม/ลบแถว-คอลัมน์ สีหัวตาราง แถวสลับสี ฟอนต์
- **กราฟ 32 แบบ** – แท่ง (กลุ่ม/ซ้อน/100%/แนวนอน/น้ำตก) เส้น พื้นที่ วงกลม โดนัท เรดาร์ กระจาย ฟองสบู่ Heatmap Treemap กรวย เกจ ฯลฯ ข้อมูลหลายชุด นำเข้า CSV ชุดสี ชื่อกราฟ แสดงตัวเลข/เปอร์เซ็นต์
- **QR Code** – ใส่ลิงก์หรือข้อความ เลือกสี พื้นโปร่งใสได้
- **สมการคณิตศาสตร์** – เขียนแบบ LaTeX พร้อมปุ่มแทรก (เศษส่วน ยกกำลัง ราก ×÷ ≤ π ∑ เมทริกซ์) และดูตัวอย่างสด เป็นเวกเตอร์คมชัด
- **กรอบรูป 183 แบบ** (เรขาคณิต ดาว ธรรมชาติ หัวใจ ป้าย ขอบฉีก/แสตมป์ ตัวอักษร A–Z ตัวเลข 0–9 พยัญชนะไทย ก–ฮ) และ **ตารางรูป (คอลลาจ) 20 แบบ** – ลากรูปจากหน้างาน แผงต่าง ๆ หรือไฟล์ในเครื่องมาวางบนกรอบ รูปเข้าไปในกรอบเอง ดับเบิลคลิกเพื่อเลือกส่วนที่แสดง ลากมุม/ล้อเมาส์เพื่อย่อขยาย พอดีกรอบ เอาออกจากกรอบ; **กรอบจากข้อความ** เลือกฟอนต์ได้; **กรอบตกแต่ง 14 แบบ** (โพลารอยด์ ฟิล์ม มือถือ แล็ปท็อป เบราว์เซอร์ แสตมป์ ฯลฯ); รูปทรงกรอบทั้งหมดใช้เป็นรูปทรงธรรมดาที่พิมพ์ข้อความได้
- **วาดอิสระ** – ปากกาและปากกาไฮไลต์
- **จัดการวัตถุ** – คัดลอกสไตล์ไปวางวัตถุอื่น, เว้นระยะเท่ากัน, ลากองค์ประกอบจากแผงมาวางตรงจุดที่ต้องการ, ค้นหาองค์ประกอบ, เลเยอร์ (ซ่อน/ล็อก/เลื่อนลำดับ), จัดกลุ่ม, จัดแนว, เส้นช่วยจัดแนวอัตโนมัติ (snap), ป้อนขนาด/ตำแหน่ง/องศา, พลิก, ความโปร่งใส, คลิกขวาเปิดเมนู
- **หลายหน้า** – เพิ่ม/ทำสำเนา/ลบ/สลับลำดับหน้า และ **โหมดนำเสนอ** เต็มจอ
- **ตั้งค่าเอกสาร** – หัวกระดาษ ท้ายกระดาษ เลขหน้า 5 รูปแบบ (ไม่แสดงในหน้าปกได้) ลายน้ำ (ลับ, ลับมาก, ร่าง, สำเนา ฯลฯ) และขอบหน้ากระดาษ 5 แบบ ใช้กับทุกหน้า และส่งออกเป็นของจริงใน Word
- **ชุดแบรนด์** เก็บสี ฟอนต์ (หัวข้อ/หัวข้อย่อย/เนื้อความ) และโลโก้ไว้ใช้ซ้ำ, แสดงระยะขอบปลอดภัย, ค้นหางานในหน้าแรก
- **เลิกทำ / ทำซ้ำ** และปุ่มลัดคีย์บอร์ด (ดูในเมนู ไฟล์ → ปุ่มลัดคีย์บอร์ด)
- **ดาวน์โหลด** – PNG (เลือกพื้นโปร่งใสได้), JPG, WEBP, SVG (เวกเตอร์), PDF (หลายหน้า ขนาดกระดาษจริงสำหรับ A4/A3/นามบัตร **เลือกและค้นหาข้อความไทยได้**), PDF สำหรับโรงพิมพ์ (300 dpi + ระยะตัดตก 3 มม. + เครื่องหมายตัด), PowerPoint (.pptx), ไฟล์โปรเจกต์ `.json` สำหรับเปิดแก้ไขต่อ, **PowerPoint และ Word ที่แก้ไขได้** (ข้อความ ตาราง กราฟเป็นของจริง; Word เลือกได้ระหว่าง "เอกสาร/รายงาน" ที่ข้อความไหลต่อกันแบบไฟล์ Word ปกติ หรือ "ตรงตามงานออกแบบ"), PDF CMYK สำหรับโรงพิมพ์; เลือกความละเอียด 0.5×–3× และเลือกหน้าได้ หลายหน้ารวมเป็น `.zip`
- **พิมพ์** ได้โดยตรงจากเบราว์เซอร์
- รองรับมือถือ และโหมดมืด

## วิธีรัน

```bash
cd design-studio
npm install
npm run dev            # เปิด http://localhost:5173
npm run build          # ได้โฟลเดอร์ dist/ นำไปวางบนเว็บโฮสต์ใดก็ได้ (Vercel, Netlify, GitHub Pages)
npm run build:single   # ได้ dist-single/index.html ไฟล์เดียว เปิดได้เลย
```

## การทดสอบอัตโนมัติ

ชุดทดสอบ `tests/e2e.cjs` เปิดแอปในเบราว์เซอร์จริงแล้วทดสอบทุกระบบทีละขั้น (126 รายการ ใน 15 หมวด) รวมถึงตรวจไฟล์ที่ดาวน์โหลดทุกรูปแบบ (ขนาดภาพ, ช่องโปร่งใส, จำนวนหน้า PDF, จำนวนสไลด์ PPTX, ไฟล์ใน ZIP)

```bash
npm i -D playwright && npx playwright install chromium   # ครั้งแรกครั้งเดียว
npm run build && npm test
```

ผลจะอยู่ที่ `tests/report/REPORT.md` และภาพหน้าจอของรายการที่ไม่ผ่าน

`npm run test:office` ทดสอบไฟล์ PowerPoint/Word ที่แก้ไขได้ โดยเปิดด้วย LibreOffice แล้วตรวจว่าข้อความไม่หาย ไม่มีภาษาแปลก ๆ ฟอนต์ถูกต้อง และเทียบภาพทีละหน้ากับต้นฉบับ (ต้องติดตั้ง LibreOffice, poppler-utils และ ImageMagick) ผลอยู่ที่ `tests/report-office/` พร้อมภาพเทียบ `compare-*.png`

`npm run test:docs` ทดสอบไฟล์ Word ของงานเอกสาร/รายงาน 9 รูปแบบ + เทมเพลต A4 แบบข้อความไหลต่อกัน (มี/ไม่มีเลขหน้า ลายน้ำ หัว/ท้ายกระดาษ ขอบกระดาษ หัวข้อ ตัวหนา/ตัวสี) ตรวจโครงสร้างไฟล์ เปิดด้วย LibreOffice และทดลองแก้ไฟล์ด้วย python-docx ว่าแก้ได้จริง (ต้องมี `pip install python-docx`) ผลอยู่ที่ `tests/report-docs/`

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `src/main.js` | หน้าแรก, รายการงาน, เปิด/นำเข้าไฟล์, routing |
| `src/editor.js` | ตัวแก้ไข: canvas, แถบเครื่องมือ, แผงด้านข้าง, หลายหน้า, undo/redo |
| `src/features.js` | ตาราง/กราฟ/QR/สมการ (ตัวแก้ไข), กรอบรูป, ข้อความโค้ง, คัดลอกสไตล์, โหมดนำเสนอ, ลากวาง |
| `src/decoframes.js` | กรอบตกแต่ง (โพลารอยด์ ฟิล์ม อุปกรณ์) |
| `src/smart.js` | สร้างตาราง QR สมการ กรอบรูป ม็อกอัป จากข้อมูล |
| `src/charts.js` | กราฟ 32 แบบ (ข้อมูลหลายชุด) |
| `src/docsetup.js` | หัว/ท้ายกระดาษ เลขหน้า ลายน้ำ ขอบกระดาษ (ใช้ร่วมกันทั้งตัวแก้ไข การส่งออกภาพ/PDF และ Word) |
| `src/office.js` | ส่งออก PowerPoint / Word ที่แก้ไขได้ |
| `src/templates2.js` | เทมเพลตที่สร้างจากโครง 16 แบบ × ธีม 5 ชุด |
| `src/patterns.js` | ลวดลายเวกเตอร์ และรายการคลังรูป |
| `src/export.js` | ส่งออก PNG/JPG/WEBP/SVG/PDF/JSON, ZIP, พิมพ์ |
| `src/templates.js` | เทมเพลตแบบปรับตามขนาด |
| `src/shapes.js` | รูปทรง เส้น สติกเกอร์ |
| `src/fonts.js` | รายชื่อและการโหลดฟอนต์ |
| `src/storage.js` | บันทึกงานใน IndexedDB |

ใช้ [MathJax](https://www.mathjax.org/) สำหรับสมการ, [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) สำหรับ QR, [PptxGenJS](https://gitbrent.github.io/PptxGenJS/) สำหรับ PowerPoint, [Fabric.js](https://fabricjs.com/) สำหรับ canvas, [jsPDF](https://github.com/parallax/jsPDF) สำหรับ PDF และ [JSZip](https://stuk.github.io/jszip/) สำหรับรวมไฟล์
