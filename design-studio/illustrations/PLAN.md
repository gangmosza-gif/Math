# แผนสร้างภาพประกอบของ Lai Studio ด้วย ChatGPT

เป้าหมายคือมีคลังภาพประกอบที่เป็นของเราเอง หน้าตาไปในทางเดียวกัน และใช้ทำเทมเพลตได้ทุกประเภท
ทั้งหมด **302 ภาพ ใน 33 ชุด** แบ่งเป็นสติกเกอร์ (พื้นหลังโปร่งใส) 264 ภาพ และฉากพื้นหลังเต็มหน้า 38 ภาพ
คำสั่งทุกข้ออยู่ในโฟลเดอร์ `batches/` (หนึ่งไฟล์ต่อหนึ่งชุด คัดลอกไปวางได้ทันที)

## 1. สไตล์ 3 แบบ (ใช้แบบเดียวต่อหนึ่งชุด)

| รหัส | สไตล์ | ใช้กับ |
|---|---|---|
| S1 | ลายเส้นน่ารัก: เส้นดำหนา สีพาสเทล ไม่ไล่สี | การศึกษา สำนักงาน ต้นไม้ อากาศ ของตกแต่ง สุขภาพ กีฬา ท่องเที่ยว ฉากสไลด์ |
| S2 | แฟลตมีพื้นผิว: ไม่มีเส้นขอบ สีธรรมชาติ มีเกรน | เทศกาลไทย อาหารไทย ตลาด สถานที่ไทย ดอกไม้ ลายไทย ฉากโปสเตอร์ เกียรติบัตร |
| S3 | 3 มิติ: ดินน้ำมันมันวาว | สติกเกอร์ 3 มิติ ตัวเลข ป้าย ฉากโพสต์โซเชียล |

คำอธิบายสไตล์ (โทนสีและน้ำหนักเส้น) ถูกเขียนซ้ำเต็ม ๆ ในทุกคำสั่ง เพื่อไม่ให้สไตล์ค่อย ๆ เพี้ยนไปจากเดิม

## 3. กติกาป้องกัน ChatGPT "หลอน"

1. **หนึ่งคำสั่ง = หนึ่งภาพ** ส่งทีละข้อ รอภาพเสร็จก่อนส่งข้อต่อไป อย่ารวมหลายภาพในข้อความเดียว
2. **หนึ่งชุด = หนึ่งแชตใหม่** ไม่เกิน 10 ภาพต่อแชต เพราะแชตยาวทำให้ ChatGPT ลืมกติกา
3. **แนบภาพตั้งต้น** ของสไตล์นั้นทุกครั้งที่เปิดแชตใหม่ พร้อมประโยคแรกที่ให้ไว้ในไฟล์ชุด
4. **ห้ามมีตัวหนังสือในภาพ** (ChatGPT เขียนภาษาไทยผิดเกือบทุกครั้ง) ตัวหนังสือค่อยใส่ในโปรแกรมของเราเอง
   ยกเว้นชุด 27 ที่เป็นตัวเลขหลักเดียว
5. ระบุจำนวนคนและสิ่งของให้ชัด เช่น "Exactly two people" และใช้มือแบบเรียบง่าย เพื่อลดปัญหามือ 6 นิ้ว
6. ระบุรายละเอียดความเป็นไทยให้ชัด เช่น ชุดนักเรียน (เสื้อขาว กางเกง/กระโปรงกรมท่า) และธงชาติ 5 แถบ
   ไม่อ้างอิงวัด สถานที่ บุคคล หรือแบรนด์ที่มีอยู่จริง
7. ขอพื้นหลังโปร่งใส ถ้าทำไม่ได้ให้ใช้พื้นขาวล้วน ระบบจะลบพื้นหลังให้เอง
   (ภาพที่ ChatGPT วาดลายตารางหมากรุกปลอมแทนพื้นโปร่งใสก็ลบให้ได้)

## 4. ขั้นตอนต่อหนึ่งชุด (ตรวจทุกภาพก่อนนำเข้า)

1. **สร้าง:** ส่งคำสั่งทีละข้อตามไฟล์ `batches/batch-XX-*.md` แล้วดาวน์โหลดเป็น PNG
2. **ตั้งชื่อ:** ตั้งชื่อไฟล์ตามที่ระบุในแต่ละข้อ เช่น `s1-students-boy-waving.png`
3. **ส่งให้ Claude:** อัปโหลดภาพทั้งชุด (หรือไฟล์ zip) ในแชต หรือวางไว้ใน `illustrations/inbox/batch-XX/`
4. **ตรวจอัตโนมัติ:** `npm run illus:check -- illustrations/inbox/batch-XX` ตรวจเรื่องต่อไปนี้:
   - ชื่อไฟล์ ขนาดภาพ และสัดส่วนภาพ
   - พื้นหลัง: โปร่งใส / ขาว / ลายตารางปลอม / มีลวดลายจนลบไม่ได้
   - วัตถุถูกตัดขอบหรือไม่ และมีที่ว่างรอบวัตถุพอไหม
   - เศษจุดเล็ก ๆ ที่กระจัดกระจาย
   - ตัวอักษรในภาพ (อ่านด้วย OCR ทั้งไทยและอังกฤษ)
   - สไตล์ตรงไหม (มีเส้นขอบ / ไม่มีเส้นขอบ / มีแสงเงาแบบ 3 มิติ)
   - ภาพซ้ำกับภาพอื่นในชุดหรือในคลัง
   - ฉาก: พื้นที่ที่เว้นไว้ใส่ข้อความโล่งจริงไหม

   ผลอยู่ใน `_check/report.md` และ `_check/contact.png` (ภาพรวมทั้งชุด แถบสี เขียว = ผ่าน, ฟ้า = แก้อัตโนมัติได้, ส้ม = ต้องดู, แดง = ไม่ผ่าน)
5. **ตรวจด้วยตา:** Claude ดู `contact.png` ทีละภาพตามเกณฑ์ข้อ 5 แล้วบันทึกผลลง `review.json`
6. **นำเข้า:** `npm run illus:import -- illustrations/inbox/batch-XX` ระบบจะ:
   - นำเข้าเฉพาะภาพที่ผ่านทั้งการตรวจอัตโนมัติและการตรวจด้วยตา
   - ลบพื้นหลัง ตัดขอบ ย่อเป็น WebP และทำภาพย่อ
   - เพิ่มลง `public/illustrations/manifest.json` ภาพจะไปขึ้นที่แผง "องค์ประกอบ" ในแถว "ภาพประกอบของเรา" และ "ฉากพื้นหลังของเรา"
7. **สั่งใหม่:** ภาพที่ไม่ผ่านจะมีคำสั่งให้สร้างใหม่ใน `_check/regenerate.md` ส่งในแชตเดิมของชุดนั้นได้เลย

## 5. เกณฑ์ตรวจด้วยตา (ทุกภาพต้องผ่านทุกข้อ)

1. ตรงกับคำสั่ง: เป็นสิ่งที่สั่งจริง จำนวนคนและสิ่งของครบตามสั่ง
2. สไตล์เหมือนภาพตั้งต้น: น้ำหนักเส้น โทนสี และสัดส่วนตัวละคร
3. ไม่มีตัวหนังสือ ตัวเลข โลโก้ หรือลายเซ็นแฝงอยู่ (รวมถึงบนป้าย เสื้อ หน้าจอ)
4. ร่างกายถูกต้อง: มือ นิ้ว ขา และใบหน้าไม่ผิดรูป
5. ความเป็นไทยถูกต้อง: ชุดนักเรียน ธงชาติ อาหาร และประเพณีไม่ผิดเพี้ยน และไม่ล้อเลียนศาสนาหรือวัฒนธรรม
6. ขอบภาพสะอาด: ไม่มีขอบขาวหรือเศษพื้นหลังเหลือหลังลบพื้นหลัง
7. ฉาก: มีที่ว่างสำหรับข้อความตรงตำแหน่งที่สั่ง และไม่มีอะไรสำคัญอยู่ชิดขอบ
8. ไม่ซ้ำกับภาพที่มีอยู่แล้ว และใช้งานได้จริงในงานออกแบบ

## 6. ขนาดไฟล์และการเผยแพร่

- สติกเกอร์ย่อเหลือไม่เกิน 1024 px (ประมาณ 40–120 KB) และฉากไม่เกิน 1600 px (ประมาณ 100–250 KB)
  ครบ 302 ภาพจะประมาณ 25–35 MB เก็บใน `public/illustrations/` และโหลดเฉพาะภาพที่เปิดดู
- เว็บทดสอบบน claude.ai เป็นไฟล์เดียว จึงยังไม่มีคลังนี้ ต้องอัปโหลดเข้าคลังไฟล์ของหน้า หรือขึ้นเว็บจริง (เช่น Vercel)
- ที่มาของภาพถูกบันทึกใน manifest ว่า "ChatGPT (สร้างตามคำสั่งของโปรเจกต์นี้)"
  ตามเงื่อนไขของ OpenAI ภาพที่สร้างเป็นสิทธิ์ของผู้สร้าง แต่คำสั่งต้องไม่เลียนแบบผลงาน ศิลปิน หรือแบรนด์ที่มีอยู่จริง

## 7. คำสั่งที่เกี่ยวข้อง

```bash
npm run illus:prompts                                   # สร้างไฟล์คำสั่งทั้งหมดใหม่ (แก้รายการภาพได้ที่ illustrations/build_prompts.py)
npm run illus:check  -- illustrations/inbox/batch-01    # ตรวจอัตโนมัติ + ภาพรวม
npm run illus:import -- illustrations/inbox/batch-01    # นำเข้าภาพที่ผ่านและอนุมัติแล้ว
npm run test:illus                                      # ทดสอบระบบตรวจ/นำเข้าด้วยภาพตัวอย่างที่มีปัญหาต่าง ๆ
```
