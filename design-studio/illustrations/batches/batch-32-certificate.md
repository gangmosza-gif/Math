   > I will send you 6 separate image requests. Use exactly the same art style, line weight and colour palette as the attached reference image for every image. Make one image per request.
2. ส่งคำสั่งด้านล่าง **ทีละข้อ** รอภาพเสร็จก่อนส่งข้อต่อไป (อย่าส่งหลายข้อในข้อความเดียว จะทำให้ภาพมั่ว)
3. ดาวน์โหลดเป็น PNG ตั้งชื่อไฟล์ตามที่ระบุ ใส่ไว้ในโฟลเดอร์ `illustrations/inbox/batch-32/`
4. ถ้าภาพมีตัวหนังสือ มือผิดรูป หรือไม่ตรงคำสั่ง ให้พิมพ์ "Please regenerate. Problems: …" แล้วระบุปัญหา

5. ครบชุดแล้วส่งภาพมาให้ Claude ตรวจ (หรือรัน `npm run illus:check -- illustrations/inbox/batch-32`) ก่อนนำเข้าทุกครั้ง
