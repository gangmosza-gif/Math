# ชุดที่ 00 · ภาพตั้งต้นกำหนดสไตล์ (ทำก่อนทุกชุด)

สไตล์: S1 ลายเส้นน่ารัก (doodle), S2 แฟลตมีพื้นผิว (flat grain), S3 3 มิติ (3D clay) · 10 ภาพ

**วิธีใช้** (ทำตามทุกครั้ง)

1. เปิดแชตใหม่ใน ChatGPT 1 แชตต่อ 1 สไตล์ (S1, S2, S3) ส่งคำสั่งทีละข้อ รอภาพเสร็จก่อนส่งข้อต่อไป
2. ภาพชุดนี้คือ "ภาพตั้งต้น" ที่จะใช้เป็นแบบของสไตล์ทั้งหมด ถ้าภาพไหนยังไม่สวย ให้สั่งสร้างใหม่จนพอใจก่อนไปชุดอื่น
3. ดาวน์โหลดเป็น PNG แล้วตั้งชื่อไฟล์ตามที่ระบุ ใส่ไว้ในโฟลเดอร์ `illustrations/inbox/batch-00/`

5. ครบชุดแล้วส่งภาพมาให้ Claude ตรวจ (หรือรัน `npm run illus:check -- illustrations/inbox/batch-00`) ก่อนนำเข้าทุกครั้ง
