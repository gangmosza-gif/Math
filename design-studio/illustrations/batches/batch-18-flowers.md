# ชุดที่ 18 · ดอกไม้และใบไม้

สไตล์: S2 แฟลตมีพื้นผิว (flat grain) · 10 ภาพ

**วิธีใช้** (ทำตามทุกครั้ง)

1. เปิด **แชตใหม่** แล้ว **แนบภาพตั้งต้นของสไตล์ S2** จากชุด 00 (เช่น `s2-anchor-*.png`) พร้อมพิมพ์ประโยคแรกนี้ก่อน:
   > I will send you 10 separate image requests. Use exactly the same art style, line weight and colour palette as the attached reference image for every image. Make one image per request.
2. ส่งคำสั่งด้านล่าง **ทีละข้อ** รอภาพเสร็จก่อนส่งข้อต่อไป (อย่าส่งหลายข้อในข้อความเดียว จะทำให้ภาพมั่ว)
3. ดาวน์โหลดเป็น PNG ตั้งชื่อไฟล์ตามที่ระบุ ใส่ไว้ในโฟลเดอร์ `illustrations/inbox/batch-18/`
4. ถ้าภาพมีตัวหนังสือ มือผิดรูป หรือไม่ตรงคำสั่ง ให้พิมพ์ "Please regenerate. Problems: …" แล้วระบุปัญหา

5. ครบชุดแล้วส่งภาพมาให้ Claude ตรวจ (หรือรัน `npm run illus:check -- illustrations/inbox/batch-18`) ก่อนนำเข้าทุกครั้ง
